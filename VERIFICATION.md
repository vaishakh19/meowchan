## Actually passed on this branch

- `npm ci`, `npm run typecheck`, `npm test` (**128/128 vitest**,
  including the new deletion-dialog and Pro-screen suites), Vite
  production build.
- `cargo test --manifest-path src-tauri/Cargo.toml` on
  `x86_64-pc-windows-msvc`: **111 passed** — including the new
  deletion-guard table (traversal normalisation, drive/scan roots,
  UNC, protected system locations and their subtrees), the licence
  decision/grace/masking tests, the entitlement round-trip and the
  scan-index removal overlay.
- `npm run app:build` (`tauri build --ci --target
  x86_64-pc-windows-msvc -- --locked`): release compilation and NSIS
  packaging succeeded.
- `dumpbin /dependents`: no external VCRUNTIME, MSVCP, sqlite3 or
  WebView2Loader DLL import (WebView2 remains an OS runtime
  dependency).
- The built executable was smoke-tested through the real WebView2
  UI (scan, large files, duplicates; zero runtime exceptions), then
  installed silently and uninstalled cleanly.

Three compile rounds were needed to get here; the errors found by CI
(struct-field typo, a moved `Option`, a missing lock-guard at two
call sites, an uninitialised overlay field, an invalid test pattern)
were fixed on the branch without removing functionality. CI also
caught a real safety hole: per-volume system locations were protected
at depth 1 only, so `D:\$Recycle.Bin\S-1-5-21\file.txt` could have
been deleted; the whole subtree is now refused on every drive.
